Quest UI Fix Preview

This page summarizes the changes applied to fix Store Quest and Earthquake Quest triggers and UI visibility, plus a small layout tweak so the Settings button no longer flickers.

What Changed

  • StoreQuest: Auto-starts when any objective interaction occurs, so the quest UI appears even if the cashier start fails.
  • EarthquakeQuest: Fixed a runtime error in _ready() (missing viewport_size) that prevented the quest UI from showing after the Slurpee interaction.
  • UI Positioning: Both quest panels are nudged down by 80px to avoid overlapping the top-right Settings button and eliminate perceived blinking/flicker.
  • Item Tips: Fixed SimpleDialogManager.show_item_dialog null-check/indentation so pickup tips display correctly (e.g., battery, water, go bag). Added a fallback start_dialog and simple position helpers for compatibility.
  • Interactive Asset Tips: Added SimpleDialog safety tips for Scenario 1 assets: window, fuse_box, candle, tv, e_fan, bucket, frying_pan.
  • Mobile Controls: Switched joystick to arrow buttons (D-pad). Movement now uses move_left/right/up/down via button press/hold.

How to Validate In-Game

  1. Open inside_the_store.tscn and run the scene.
  2. Interact with the cashier: Store Quest UI should appear on the right, below the Settings button.
  3. Interact with the slurpee machine: Earthquake Quest should instantiate and its UI should also appear below the Settings button; Store Quest UI hides during the quake.
  4. Pick up any item (e.g., battery, water_bottle, go_bag): a simple tips dialog should pop above the player with header “TIPS”.
  5. Interact with assets (e.g., window, fuse_box, candle): a SimpleDialog safety tip should display after the short self-talk.

Files Updated

  • store_quest.gd — Auto-start in complete_objective(); quest box positioned with an extra 80px top offset.
  • earthquake_quest.gd — Initialize viewport_size in _ready(); quest box positioned with an extra 80px top offset.
  • SimpleDialogManager.gd — Fix show_item_dialog logic; add start_dialog and position helpers.
  • MobileControls.tscn — Added ArrowButtons container with Up/Down/Left/Right buttons.
  • mobile_controls.gd — Enabled D-pad mode; mapped button_down/up to movement actions; hid joystick.
  • pause_menu.gd / game_settings.gd — Block/unblock ArrowButtons when overlays are active.

Notes

  • If the Earthquake Quest still doesn’t appear, confirm earthquake_quest.tscn is instanced and added to get_tree().current_scene by slurpee.gd.
  • Ensure players are in the Player2 group for Interaction Areas to register and prompt correctly.
