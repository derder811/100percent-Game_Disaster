Quest UI Positioning Changes - Left Side Migration

Both the Earthquake Quest and Store Quest UI elements have been successfully moved from the right side to the left side of the screen.

Technical Changes Made:

  • earthquake_quest.tscn: Changed anchors_preset from 1 to 0, anchor_left/right from 1.0 to 0.0, adjusted offsets for left positioning
  • earthquake_quest.gd: Updated _reposition_quest_box() function to use left-side anchoring with positive margins
  • store_quest.tscn: Changed anchors_preset from 1 to 0, anchor_left/right from 1.0 to 0.0, adjusted offsets for left positioning
  • store_quest.gd: Updated _reposition_quest_box() function to use PRESET_TOP_LEFT and positive offset calculations

Benefits of Left-Side Positioning:

  • Better visual balance with game elements typically positioned on the right
  • Improved readability as most users scan from left to right
  • Consistent positioning across both quest systems
  • Maintains proper spacing and visual hierarchy
