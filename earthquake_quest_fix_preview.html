🚨 Earthquake Quest Visibility Fix

Problem Identified

🐛 Issue:

The earthquake quest was not showing during the earthquake because the animation function was still using right-side positioning logic while the quest box had been moved to left-side anchoring.

This caused the quest box to animate to the wrong position (off-screen on the right) instead of sliding in from the left.

Fixed Earthquake Quest Display

✅ Quest box now properly slides in from the left during earthquake

Technical Fix Applied

🔧 Solution:

Updated the show_quest_box_with_animation() function in earthquake_quest.gd to use left-side positioning logic that matches the new anchor settings.

❌ Before (Broken)

# Start position (off-screen to the right) quest_box.offset_left = 40.0 # Target position (anchored to right edge) var target_left = -(quest_box.size.x + margin) var target_right = -margin

✅ After (Fixed)

# Start position (off-screen to the left) quest_box.offset_left = -quest_box.size.x - 40.0 # Target position (anchored to left edge with margin) var target_left = margin var target_right = margin + quest_box.size.x

What This Fix Ensures

  • ✅ Quest box appears immediately when earthquake starts
  • ✅ Smooth slide-in animation from the left side
  • ✅ Proper positioning on all screen sizes
  • ✅ Consistent with store quest left-side positioning
  • ✅ Maintains all quest functionality (objectives, timers, etc.)
